# Santo Asfalto

![Santo Asfalto](https://raw.githubusercontent.com/AlexanderPuglisi-Mods/santo-asfalto/main/images/catalogo.png)

Baroque black-and-gold streetwear for **skate.** with **ReSkate**: 19 new cosmetic items. No original item is replaced.

## Items

| Category | Items |
|---|---|
| Tops | Felpa Techwear · Felpa Zip · Camicia Damasco · Camicia Hawaiana · Crop SacroCuore · Giacca AltaModa |
| Bottoms | Pantalone NeonOro · Pantalone NeonRosso · Pantalone Smoking · Pantalone Techwear · Bermuda Denim · Gonna Pieghe |
| Lingerie | Reggiseno Pizzo · Reggiseno Sport · Perizoma Pizzo · Slip Sport |
| Board | Tavola ExVoto (deck) · Ruote Raggiera (wheels) · Truck Oro (trucks) |

## Installation

- **ReSkate Launcher:** open **MODS** and install *Santo Asfalto*.
- **Manual:** extract the zip into its own folder inside the game's `Mods` folder (next to `Skate.exe`). Do not import it with Studio's *ADD .FBMOD*.

## Italiano

Streetwear barocco nero e oro per **skate.** con **ReSkate**: 19 capi nuovi, nessun capo originale sostituito. Si installa dalla pagina **MODS** del launcher di ReSkate, oppure estraendo lo zip in una cartella dentro `Mods`, accanto a `Skate.exe`.
